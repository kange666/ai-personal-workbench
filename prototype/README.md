# AI 个人工作台原型说明

所有页面均使用演示数据，不读取真实 Codex 对话、Git 内容或密钥。页面画布统一为 1440×900。

## 灰度原型

1. `01-dashboard.png`：查看今日任务、本周进度、Token、项目、报告和 AI 建议；主要入口是“查看今日计划”和“新增任务”。
2. `02-tasks.png`：在每日、每周、项目任务和 AI 草稿间切换；右侧详情用于编辑任务归属、日期和备注。
3. `03-calendar.png`：左侧按日期查看每日任务，顶部展示整周任务；右侧甘特图查看项目阶段。
4. `04-reports.png`：左侧选择日报、周报或月报；右侧完成编辑、锁定、重新生成及 Word 导出。
5. `05-tokens.png`：查看 Token 趋势、上下文占用、项目排行和高消耗会话。
6. `06-knowledge.png`：搜索已确认知识，按类型和项目筛选，并通过 AI 问答追溯来源。

## 风格方案

- `a-clean`：固定左侧导航和规则卡片网格，蓝白清爽，适合作为默认方案。
- `b-command`：折叠图标导航、深色工作区和固定 AI 助手侧栏，信息密度最高。
- `b-command/c-theme`：保留 B 的指挥中心布局，切换为 C 的米白、低饱和绿色和橙色主题。
- `c-timeline`：顶部主导航、左侧项目筛选和温和纸张配色，突出时间规划与复盘。

每套风格包含首页、任务中心、日历甘特和组件样式板。
